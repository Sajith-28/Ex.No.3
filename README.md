# Ex.No.3 – Scenario-Based Report Development Utilizing Diverse Prompting Techniques

### DATE: 04-11-2026

### REGISTER NUMBER: 212223240144

## Aim

To write prompts for the following prompt types and evaluate them using the generated AI responses:

1. Straightforward Prompts
2. Tabular Format Prompting
3. Preceding Question Prompting
4. Missing Word Prompting

## Explanation

**Use Case: AI-Based Smart Healthcare Assistant**

An AI-Based Smart Healthcare Assistant is an intelligent healthcare platform designed to make everyday healthcare management easier for patients. It helps patients schedule doctor appointments, receive medication reminders, get answers to common health questions, and monitor daily wellness activities.

## Procedure

### 1. Straightforward Prompts

**Prompt:**

```text
Design an AI-powered Smart Healthcare Assistant that helps patients schedule appointments, receive medication reminders, answer common health questions, and monitor daily wellness activities.
```

**Output:**

```text
Let's design an AI-Powered Smart Healthcare Assistant as a modern, intelligent healthcare platform that makes everyday healthcare management easier for patients.

The system will have four core modules:

1. Smart Appointment Scheduling

- Book doctor appointments.
- View available doctors and time slots.
- Reschedule or cancel appointments.
- Receive appointment confirmations.

2. Medication Reminders

- Set medicine schedules.
- Receive timely notifications.
- Track taken and missed doses.
- View medication history.

3. AI Health Chatbot

- Answer common health questions.
- Provide general health information.
- Explain common medical terminology.
- Recommend professional consultation when appropriate.

4. Daily Wellness Monitoring

- Track daily steps and physical activity.
- Monitor sleep duration.
- Track water intake.
- Display daily wellness progress.

Proposed Technology Stack:

- Frontend: Angular / React
- Backend: Python FastAPI
- Database: MongoDB
- AI Chatbot: LLM API
- Notifications: Firebase Cloud Messaging

Overall System Architecture:

Patient Mobile App / Web Dashboard
FastAPI Backend
Appointment Service
Medication Service
AI Chatbot Service
Wellness Service
MongoDB + AI Model + Notification Service
```

**Evaluation:**

The response clearly explains the major modules of the Smart Healthcare Assistant. It covers appointment scheduling, medication reminders, an AI health chatbot, and daily wellness monitoring. It also provides a suggested technology stack and system architecture.

### 2. Tabular Format Prompting

**Prompt:**

```text
Present the major features of the AI-Based Smart Healthcare Assistant in a table containing Feature, Purpose, and Example.
```

**Output:**

```text
| Feature | Purpose | Example |
|---|---|---|
| Smart Appointment Scheduling | Helps patients book, reschedule, and cancel doctor appointments. | A patient books an appointment with a cardiologist for Monday. |
| Medication Reminders | Reminds patients to take medicines at the prescribed time. | Sends a notification to take medicine at 8:00 AM. |
| AI Health Chatbot | Answers common health-related questions and provides general health information. | A patient asks, "What are the common symptoms of dehydration?" |
| Daily Wellness Monitoring | Tracks daily physical activities and wellness habits. | Records 5,000 steps, 7 hours of sleep, and daily water intake. |
| Health Progress Dashboard | Displays patient wellness information and activity history. | Shows weekly activity, sleep, and hydration reports. |
| Notification System | Sends alerts about appointments, medications, and health activities. | Notifies a patient one day before a doctor appointment. |
| Patient Profile Management | Stores and manages basic patient information and preferences securely. | Saves patient name, age, contact details, and appointment history. |
| Personalized Health Suggestions | Provides general wellness suggestions based on recorded activities. | Suggests improving sleep habits based on sleep tracking data. |

Conclusion:

The AI-Based Smart Healthcare Assistant simplifies healthcare management by combining appointment scheduling, medication reminders, AI-powered health assistance, and daily wellness monitoring in one platform.
```

**Evaluation:**

The response presents the major features in a well-organized table containing Feature, Purpose, and Example. It makes the information easy to understand and compare. It also includes additional features such as a health progress dashboard, notification system, and patient profile management.

### 3. Preceding Question Prompting

**Prompt:**

```text
Why are AI-powered healthcare assistants becoming important in modern hospitals? Explain how they improve patient care, appointment management, medication adherence, and wellness monitoring.
```

**Output:**

```text
AI-powered healthcare assistants are becoming important in modern hospitals because they save time, reduce manual work, and improve healthcare services. They help patients and healthcare professionals manage medical activities more efficiently.

1. Improved Patient Care

- Provide quick answers to common health-related questions.
- Help patients access health information anytime.
- Guide patients to consult doctors when necessary.
- Reduce the workload of healthcare staff.

2. Better Appointment Management

- Allow patients to book appointments online.
- Show available doctors and time slots.
- Help reschedule or cancel appointments.
- Send automatic appointment reminders.

3. Improved Medication Adherence

- Send reminders to take medicines on time.
- Maintain medication schedules.
- Track taken and missed doses.
- Help patients follow their prescribed treatment properly.

4. Effective Wellness Monitoring

- Track daily physical activities and steps.
- Monitor sleep duration and water intake.
- Display daily and weekly wellness reports.
- Provide general health and fitness suggestions.

Conclusion:

AI-powered healthcare assistants improve patient care by providing timely support, simplifying appointment management, encouraging proper medication use, and monitoring daily wellness. They make healthcare services more accessible, efficient, and patient-friendly.

Note: AI assistants support healthcare professionals but do not replace doctors or provide emergency medical treatment.
```

**Evaluation:**

The response explains the importance of AI-powered healthcare assistants in modern hospitals. It covers improved patient care, appointment management, medication adherence, and wellness monitoring. The information is presented using clear headings and bullet points.

### 4. Missing Word Prompting

**Prompt:**

```text
Complete the following sentences using suitable words related to the AI-Based Smart Healthcare Assistant.

1. Patients can schedule __________ through the AI assistant.
2. The assistant sends __________ reminders to patients.
3. Daily health activities are monitored using __________ tracking.
4. AI provides basic __________ information.
5. The system reminds patients about __________ appointments.
```

**Output:**

```text
1. Patients can schedule doctor appointments through the AI assistant.

2. The assistant sends medication reminders to patients.

3. Daily health activities are monitored using wellness tracking.

4. AI provides basic health information.

5. The system reminds patients about upcoming appointments.
```

**Evaluation:**

The response successfully completes all five sentences using suitable words related to the healthcare assistant. All answers are relevant to the given context and demonstrate the AI system's ability to understand incomplete sentences.

## Conclusion

The four prompting techniques were successfully implemented using the AI-Based Smart Healthcare Assistant scenario. Each prompting technique generated a different type of response. Straightforward Prompting provided a direct explanation, Tabular Format Prompting organized information into a table, Preceding Question Prompting generated a detailed explanation, and Missing Word Prompting completed incomplete sentences using contextual understanding.

## Result

Thus, the various types of prompts were executed successfully, and the report was generated using the AI-Based Smart Healthcare Assistant scenario.
